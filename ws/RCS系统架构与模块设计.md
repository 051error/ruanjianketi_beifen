# 仓储多机器人调度控制系统 (RCS) 架构与模块设计

## 一、UI 呈现与事件接入

### 1.1 MainForm：纯窗口容器
- **职责定位**：
  作为最外层的纯窗口容器，仅负责界面控件树的挂载排布与系统原生鼠标、键盘输入事件的监听和委托转发，不包含任何业务调度逻辑与矩阵几何运算。
- **界面布局**：
  采用左侧全屏纯矢量渲染画布与右侧参数控制面板的双栏布局，支持右侧控制面板一键最小化折叠与展开，以在操作时自适应最大化显示地图视口。

### 1.2 视口控制器：平移、缩放
- **视口变换操作**：
  支持鼠标左键与中键拖拽平移视口、以当前鼠标指针所在屏幕像素为中心锚点的连续平滑缩放，以及将网格地图整体平移居中对齐于当前视口。
- **双向坐标投影与排他过滤**：
  统一负责屏幕像素坐标、物理世界米制坐标与地图离散栅格坐标之间的双向正逆投影计算；内置状态监控卡片与操作按钮区域的点击命中排他性拦截，避免在点击控件时误触发视口平移或网格拾取。

### 1.3 交互与业务呈现
- **单机交互呈现**：
  负责单机模式下的目标网格点击拾取与红色靶心绘制；点击同一目标触发取消导航；点击确认按钮启动自动导航；在移动过程中点击其他网格触发即时动态换道。
- **多机协同呈现**：
  负责多机模式下的机群数量规模切换、机群随机排布与对角半区专属目标分配、多机协同导航启停控制，以及全机群到达专属目标的耗时秒表统计与状态提示。
- **高性能纯矢量渲染**：
  基于前后物理位姿执行高刷新率姿态平滑插值，彻底消除物理步进阶梯跳顿；内部全生命周期复用绘图画笔与矢量路径资源，消除内存垃圾回收卡顿；仅向前绘制规划下发的未来路径，消除已走过历史路段与向后倒拉线。

## 二、中间层：调用 UI 下发的命令，上传下层仿真快照

### 2.1 调用 UI 下发的命令
- **调度控制门面**：
  统一接收来自用户界面的控制意图并下发到底层，包括单机自动导航指令、单机导航取消制动、多机搬运作业任务创建、随机搬运任务分派，以及仿真时钟的启动、暂停、继续、全局重置和单步微元步进。
- **架构隔离屏障**：
  作为用户界面表现层与底层纯物理仿真层之间的唯一安全屏障，严格保证单向依赖与调用闭环，上层无法越位直接篡改机器人位姿坐标或底层时空预约状态。

### 2.2 上传下层仿真快照
- **不可变权威状态快照**：
  在每个仿真时钟周期统一构建并向上发布包含仿真步数、仿真全局物理时间、引擎运行状态、全机群物理位姿与航向、线速度与角速度、栅格绝对占用池、时空预约锁集合以及安全碰撞事件的不可变权威快照。
- **无界面独立运行支持**：
  支持完全脱离任何图形窗口环境在后台独立高速运行，满足单元测试、算法推演与批量化无界面调度的需求。

## 三、核心仿真层

### 3.1 地图（上货区、卸货区、等待区）
- **站点类型规划**：
  - **上货区**：供机器人驶入停靠、装载货物的专属作业网格；
  - **卸货区**：供机器人驶入停靠、卸下货物的目标作业网格；
  - **等待区**：空闲机器人的默认待命与充电池停泊网格。
- **地图配置源**：
  - **外部导入 JSON 文件**：支持外部结构化地图配置文件的解析与严格校验，自动拦截地图尺寸非法、障碍物越界、站点重叠及初始小车重叠等错误；
  - **随机生成**：支持标准规格（如 30×30 正交网格，单格物理尺寸 0.55 米）的清空地图生成、无冲突多机随机部署及站点自动化排布。

### 3.2 机器人
- **通信机制**：
  - **接收控制信息（基础物理定量指令）**：
    - **前进-位移**：接收定量前进位移参数，驱动车身严格向前直线平稳推进；
    - **转向-角度**：接收定量自旋角度参数，驱动车身执行原地自旋；
    - **制动停止**：接收制动信号，按物理减速度平滑滑行停稳。
  - **上传本机状态**：
    - **机器人编号**：机群全局唯一身份标识；
    - **速度**：当前实时线速度与旋转角速度；
    - **位置（栅格）**：车底传感器通过中心读码确认的离散栅格坐标；
    - **任务状态**：处于待命、前往上货点、等待上货、前往卸货点、等待卸货等全状态机阶段；
    - **负载状态**：标记当前是否处于载货状态；
    - **电量**：动力电池余量与单机等待通行授权时长。
- **其他参数（动力学配置）**：
  - **最大速度**：默认最大线速度 1.5 米/秒；
  - **最大加速度**：默认最大线加速度与制动减速度 1.5 米/平方秒（梯形平滑加减速，禁止突变）；
  - **最大角速度**：默认最大自旋角速度 180 度/秒；
  - **最大角加速度**：默认最大角加速度 360 度/平方秒（平滑加减速旋转，禁止角速度突变）。
- **运动学模型与正交航道约束**：
  - 差速原地转向模型，前进位移与原地自旋严格物理互斥（行驶中拒绝接收转向指令，旋转中拒绝接收前进指令）；
  - 直道连续巡航计算：向前探测直道末端转弯点或终点的累积距离，避免以单格距离频繁截断导致走走停停；
  - 正交航道正中轴线横向纠偏贴合：水平直行时严格锁定纵向中心线，垂直直行时严格锁定横向中心线，确保小车轨迹与规划蓝色虚线完全重合，且 100% 穿过每个栅格的物理正中心；
  - 拐弯前与到站停稳精准归心：在转弯自旋前及到站停稳时校准物理坐标至网格正中心，最终朝向端正对齐四个正交正方向（0°, 90°, 180°, 270°）。

### 3.3 算法
- **任务分配**：
  搬运任务全生命周期状态机驱动，结合空闲就近匹配、作业站点关联与优先级机制进行全自动派单与闭环流转。
- **路径规划**：
  - **单机路径规划**：
    - 融入朝向状态的三维空间搜索，在实际移动代价中融入转向成本惩罚，并结合距离与转向开销综合启发式，在开阔对角场景下优先规划为单次转弯的标准 L 型直道；
    - 支持纯拓扑跳数步长代价、无启发式的经典波前最短路算法切换。
  - **多机路径规划**：
    支持时间窗口分层协作算法（WHCA*）等时空多智能体寻路，在时空二维展开图上搜索无冲突轨迹。
- **死锁检测与应急处理**：
  - **死锁检测**：
    - **停滞时间**：单机在同一节点累计等待通行授权时间达到安全阈值时触发警告；
    - **资源环**：周期性监测多车循环依赖等待链。
  - **死锁处理**：
    - **局部路径重规划**：绕开被锁死的拥堵节点，动态重新规划局部绕行路径；
    - **优先级退让**：低优先级或空载小车主动后退或让出十字路口关键时空资源；
    - **报警**：持续阻塞且无法自适应消解时向控制台触发声光报警并记录事件日志。
- **避碰与时空互斥管理**：
  - **栅格绝对占用锁**：物理上锁闭当前车身实际占据的网格；
  - **栅格进入预约锁**：前向申请未来通行网格的时空通行权；
  - **无向通道边时空锁**：锁闭两栅格之间的双向通行通道，绝对杜绝两机在通道内对向驶入正面碰撞；
  - **双格安全锁与地标确认交接**：小车在两格之间行驶时维持原格占用、新格预约以及通道边锁定以防后车追尾；只有当小车传感器确认对准新栅格正中心时，才原子化移交占用并释放原格与通道边，同时动态清扫身后已完全驶离的历史网格，根除转角栅格资源残留；
  - **独立几何包络碰撞检测**：以车身几何外包络半径进行连续圆形包络相交检测，独立于逻辑预约锁作为最终防撞安全底线。

## 四、测试

- **全覆盖单元测试与集成测试验证**：
  - 外部地图文件结构化解析、非法尺寸与越界重叠防御校验；
  - 路径规划算法在开阔对角场景下的少转弯航线与纯距离搜索验证；
  - 搬运作业任务从创建、指派、行进、上货、前往卸货到完成的全生命周期闭环；
  - 栅格空间绝对互斥与通道边对向防死锁冲突拦截验证；
  - 仿真引擎确定性时钟推进精度与无界面环境独立运行测试；
  - 独立几何包络碰撞检测触发与安全自动暂停保护；
  - 动力学平滑加减速积分与前进/自旋严格物理互斥约束；
  - 渲染层位姿平滑插值精度与不可变快照线程安全；
  - 重新设置目标后旧路径与旧目标预约资源的原子释放；
  - 长直道连续全速巡航无停顿与到站正交航向端正对齐测试；
  - 转角栅格驶离后占用资源彻底清空验证；
  - 正交航道中轴线贴合精度测试（横向轨迹偏差受控于毫米以内，严格穿过每个栅格物理正中心）。
